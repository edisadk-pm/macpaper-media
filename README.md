# MacPaper media

Video loops and dynamic wallpapers for MacPaper, a desktop wallpaper app for macOS.

The app downloads each file from this repository's
[Releases](https://github.com/edisadk-pm/macpaper-media/releases) the first time someone picks
that wallpaper, so the app itself stays small. The files aren't meant to be browsed here.

| File | Kind |
| --- | --- |
| `prism.mp4`, `crimson.mp4`, `silver-rings.mp4`, `diamond.mp4`, `starburst.mp4`, `threads.mp4` | Abstract video loops, HEVC, 2958×1664 |
| `alps.heic`, `fuji.heic`, `cyprus.heic`, `dome.heic`, `fletschhorn.heic` | Dynamic wallpapers that change through the day |

Each file belongs to its original creator. If you made one of them and want it removed, open an
issue.
